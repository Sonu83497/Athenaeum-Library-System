# API Documentation

Full interactive docs are auto-generated by FastAPI at `/docs` (Swagger UI)
and `/redoc` once the backend is running.

Base URL: `VITE_API_URL` (frontend) / whatever host you deploy the backend
to. All endpoints are prefixed `/api`.

All error responses follow:
```json
{ "success": false, "message": "Human-readable message" }
```

## Auth (`/api/auth`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/auth/register` | none | Register a new member account |
| POST | `/api/auth/login` | none | Log in, returns a JWT |
| GET | `/api/auth/me` | any | Current authenticated user |

## Books (`/api/books`)

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/books` | none | Search/filter/paginate books. Query params: `q`, `category`, `author`, `publisher`, `availability` (`available`\|`unavailable`), `publication_year`, `sort_by` (`title`\|`newest`\|`availability`), `page`, `page_size` |
| GET | `/api/books/{id}` | none | Book detail |
| POST | `/api/books` | admin/librarian | Create book |
| PUT | `/api/books/{id}` | admin/librarian | Update book |
| DELETE | `/api/books/{id}` | admin/librarian | Delete book |

## Members (`/api/members`)

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/members` | admin/librarian | List/search members |
| GET | `/api/members/me` | any | Current user's own member profile |
| GET | `/api/members/{id}` | admin/librarian | Member detail |
| PUT | `/api/members/{id}` | admin/librarian | Update status/phone |

## Borrowing (`/api/borrow`)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/borrow` | admin/librarian | Issue a book to a member |
| POST | `/api/borrow/{id}/return` | admin/librarian | Process a return (auto-calculates fine if overdue) |
| GET | `/api/borrow` | admin/librarian | All transactions (latest 200) |
| GET | `/api/borrow/my` | any member | Current user's borrowing history |

## Fines (`/api/fines`)

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/fines` | admin/librarian | All fines |
| GET | `/api/fines/my` | any member | Current user's fines |
| PUT | `/api/fines/{id}/pay` | admin/librarian | Mark a fine as paid |

## Reports (`/api/reports`)

| Method | Path | Auth | Description |
|---|---|---|---|
| GET | `/api/reports/dashboard` | admin/librarian | Aggregate stats (books, members, overdue, fines) |
| GET | `/api/reports/borrowing?months=6` | admin/librarian | Monthly borrow/return trend |
